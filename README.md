# ACHFlow

Production-grade ACH payment processing and reconciliation platform.

## Core goals

- Safe ACH debit and credit processing
- Idempotent payment submission
- Asynchronous queue-based execution
- Transactional outbox
- Immutable ledgering
- Retry and unknown-outcome handling
- Webhook notifications
- Reconciliation and auditability
- AI-assisted development with strict guardrails
